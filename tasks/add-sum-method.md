# Task: Add a method to sum two numbers

## Target project
- Workspace project ID: `ConsoleApp1`
- Project directory: `D:\.Net Core\ConsoleApp1`

## Requirements
Add a public C# method named `Sum` that accepts two `int` parameters and returns their sum as an `int`.

Follow the project's existing namespace, class organization, and coding conventions. Keep the change focused and do not add dependencies or modify unrelated functionality.

## Acceptance criteria
- `Sum(2, 3)` returns `5`.
- `Sum(-2, -3)` returns `-5`.
- `Sum(-2, 3)` returns `1`.
- `Sum(0, 0)` returns `0`.
- The project builds successfully.
- Add tests for these cases if the project already has a test suite.
